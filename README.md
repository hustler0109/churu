# Mantriyon Ki Chhatri — Immersive Rajasthani Website

This is a responsive, animated bilingual website prototype.

## Run
Open `index.html` in Chrome/Edge, or run:
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Features
- Full-screen cinematic hero with slow image movement
- Animated loading emblem and scrolling heritage marquee
- Scroll-triggered reveal animations
- Animated family lineage visual and original family-tree artwork
- Rajasthani-inspired palette, textures and ornamental motifs
- Hover motion on art/gallery tiles
- English/Hindi language switch
- Responsive navigation and mobile layout
- CMS concept preview (not a connected CMS)

## Photo customization
Ten supplied photographs are included in assets/event-*.jpg and displayed in the gallery. The supplied architectural photo is used as the hero and architecture illustration. Photos open at full resolution in a new tab. No external photo service is needed for these event images.


## Interactive photo tour
- Added a 24-view photo tour using the supplied monument and courtyard photographs.
- Drag to pan, mouse-wheel or controls to zoom, use hotspots and the scene list to navigate.
- The tour is intentionally described as photo-based: the supplied images are regular photographs, not stitched 360-degree panoramas.
- All tour images are bundled locally in `assets/tour-*.jpg`.


## Visual refresh
The virtual tour has been redesigned with a cinematic full-width photo stage, editorial typography, a horizontal thumbnail filmstrip, keyboard navigation and simpler zoom controls. The experience remains a curated photo tour, not a stitched 360 panorama.
